# Tropical Island

A sunny third-person island exploration game for the browser, built phones first on Three.js.

**Play it live:** https://tropical-island.bles-software.com/

![Tropical Island](docs/cover.jpg)

A sun-soaked island of palm groves, lagoons and hidden treasures. Third-person exploration with touch controls.

## Run it

```bash
npm ci
npm run dev     # local dev server
npm test        # unit tests
npm run build   # production build into dist/
```
